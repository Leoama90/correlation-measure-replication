# correlation-measure-replication
The aim of this repository is to store the code needed to replicate and use the code from the paper "Correlation Measures in Metagenomic Data: The Blessing of Dimensionality". 

# Versions

The R version used was the  4.5.3.
Rstudio version was 2026.06.0+242.

# Syntax
